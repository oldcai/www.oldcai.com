FastMD Privacy Policy

oldcai
2026-07-12
FastMD

Effective date: 2026-07-12

Last updated: 2026-09-30

English

Summary

FastMD is local by default. It has no FastMD account, advertising, analytics, telemetry, remote logging, or background upload. Your Markdown documents remain on your Mac unless you explicitly choose to publish a preview through Cloudflare or here.now.

Information stored on your Mac

FastMD stores only app settings needed for its features, including the last window frame, per-document translation targets, and security-scoped bookmarks for folders you explicitly authorize. Document contents and exported files remain in locations you choose. FastMD does not send these settings to the developer.

Optional preview publishing

When you choose Publish Preview…, FastMD first asks for confirmation. The confirmation names the operator that will receive the upload and how long the link lasts, and it is asked separately for each operator: agreeing to publish to one never grants consent for the other. If you accept and continue, the app sends an HTML snapshot of the current Markdown document and readable local resources explicitly referenced by that document to that operator, which creates a temporary, publicly accessible link.

You choose how long the link lives from the countdown in the publish sheet, and FastMD remembers that choice for the next publish:

  • 1 hour (default) — Cloudflare. FastMD uses Cloudflare's documented temporary-preview REST API and receives a temporary workers.dev link. Cloudflare returns credentials for a short-lived temporary preview account; FastMD holds them only in memory during publishing and discards both the token and private claim link instead of storing or exposing them. If REST publishing is unavailable or the package exceeds its limits, FastMD may load the official Cloudflare Drop page in a visible, non-persistent browser sheet as a fallback. Closing or cancelling the sheet stops the work.
  • 24 hours — here.now. FastMD uses here.now's documented anonymous publishing REST API and receives a temporary here.now link. No account or API key is used. here.now returns a claim token and claim link that would make the site permanent; FastMD never reads or stores either, which is what keeps the link self-expiring. This path has no browser fallback: if here.now cannot publish, FastMD reports the failure instead of silently publishing somewhere else. Uploaded files travel directly to the presigned storage endpoint here.now returns, and FastMD refuses any endpoint outside here.now and the exact storage host it is known to use.

This optional transfer is used only to provide the publishing feature. FastMD does not associate the upload with a FastMD account or use it for tracking, advertising, or analytics. Do not publish confidential, personal, or third-party material unless you have permission to make it public.

The operator you publish to may process uploaded content, IP addresses, service logs, cookies used by the browser fallback, and related technical information under its own terms: Cloudflare's Privacy Policy and Terms, or here.now's Privacy Policy and Terms. The developer does not control their retention or processing. If you do not use this feature, FastMD makes no app-initiated network request.

On-device document reading assistance

On supported macOS 26 or later Macs, FastMD uses Apple's Foundation Models framework for optional document summaries and follow-up questions. The current document snapshot and reading conversation remain in memory for that window and are discarded when the reading session closes. FastMD does not send this content to the developer or a network AI service, and this feature requires no FastMD account.

Quick Look and local files

The bundled Quick Look extension is sandboxed and read-only. It does not have network access. FastMD requests user-selected file or folder access only for opening and saving documents, displaying referenced local resources, showing same-folder files, and following external saves.

Tracking and third-party SDKs

FastMD does not track you and contains no advertising, analytics, or tracking SDKs.

Your choices

  • Decline folder access; the document remains usable, while folder-dependent features may be limited.
  • Do not use preview publishing; no document content is transmitted by FastMD.
  • Remove local settings by uninstalling the app and deleting its app container in macOS.
  • A published preview expires automatically at the deadline shown in the publish sheet. FastMD cannot guarantee immediate deletion by Cloudflare or here.now after publishing.

Contact

Questions or requests about this policy: oldcai.com@gmail.com

简体中文

概要

FastMD 默认仅在本机工作。应用无需 FastMD 账户，不含广告、分析、遥测、远程日志或后台上传。除非你主动选择通过 Cloudflare 或 here.now 发布预览，否则 Markdown 文档始终留在你的 Mac 上。

保存在 Mac 上的信息

FastMD 只保存功能所需的本机设置，包括最近一次窗口位置、按文档记住的翻译目标，以及你明确授权的文件夹安全作用域书签。文档内容和导出文件保存在你选择的位置。这些设置不会发送给开发者。

可选的预览发布

当你选择 Publish Preview… 时，FastMD 会先要求确认。确认框会点名接收上传的运营方和链接时长，并且按运营方分别询问一次：同意发布给其中一方，绝不代表同意另一方。接受并继续后，应用会把当前 Markdown 文档的 HTML 快照，以及文档明确引用且可读取的本地资源发送给该运营方，由其生成一个临时、公开可访问的链接。

链接存活多久由你在发布面板的倒计时上选择，FastMD 会记住这个选择用于下次发布：

  • 1 小时（默认）—— Cloudflare。 FastMD 调用 Cloudflare 已公开的临时预览 REST API，得到临时 workers.dev 链接。Cloudflare 会返回一个短期临时预览账户的凭证；FastMD 只在发布期间将其保存在内存中，并丢弃临时令牌和私密认领链接，不保存也不展示。如果 REST 发布不可用，或文件包超出其限制，FastMD 可能在可见、非持久化的浏览器面板中加载 Cloudflare Drop 官方页面作为兜底。关闭或取消面板会停止处理。
  • 24 小时 —— here.now。 FastMD 调用 here.now 已公开的匿名发布 REST API，得到临时 here.now 链接，不使用任何账户或 API Key。here.now 会返回可将站点转为永久的认领令牌和认领链接；FastMD 从不读取也不保存它们，这正是链接会自动过期的原因。这条路径没有浏览器兜底：here.now 发布失败时 FastMD 会如实报错，而不会悄悄改发到别处。文件直接上传到 here.now 返回的预签名存储地址，FastMD 会拒绝 here.now 及其实测存储主机以外的任何地址。

该可选传输仅用于提供发布功能。FastMD 不会把上传内容关联到 FastMD 用户账户，也不会用于追踪、广告或分析。请勿发布机密信息、个人信息，或你无权公开的第三方内容。

你发布到的运营方可能依据其各自条款处理上传内容、IP 地址、服务日志、浏览器兜底使用的 Cookie 和相关技术信息：Cloudflare 的隐私政策与条款，或 here.now 的隐私政策与条款。开发者无法控制它们的保留与处理方式。如果你不使用此功能，FastMD 不会主动发起网络请求。

设备内文档阅读助手

在支持该功能且运行 macOS 26 或更高版本的 Mac 上，FastMD 使用 Apple Foundation Models 框架提供可选的文档摘要与后续问答。当前文档快照及阅读对话只保留在该窗口的内存中，并在阅读会话关闭后丢弃。FastMD 不会将这些内容发送给开发者或网络 AI 服务，也不要求 FastMD 账户。

“快速查看”和本地文件

随附的“快速查看”扩展运行在只读沙箱中，没有网络权限。FastMD 仅为打开与保存文档、显示引用的本地资源、展示同文件夹文件，以及跟随外部保存而请求用户选择的文件或文件夹权限。

追踪与第三方 SDK

FastMD 不会追踪你，也不包含广告、分析或追踪 SDK。

你的选择

  • 你可以拒绝文件夹访问；文档仍可使用，但依赖文件夹的功能可能受限。
  • 你可以不使用预览发布；FastMD 不会传输文档内容。
  • 你可以卸载应用并删除其 macOS App 容器，以移除本机设置。
  • 已发布的预览会在发布面板显示的到期时间自动失效；发布后，FastMD 无法保证 Cloudflare 或 here.now 会立即删除内容。

联系

有关本政策的问题或请求：oldcai.com@gmail.com
