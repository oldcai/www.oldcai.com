oldcai
2026-07-12
FastMD

FastMD is a native macOS editor where the rendered Markdown document remains readable while individual blocks are edited in place. A hover-revealed Listen control narrates rendered blocks with available system voices, and a built-in Interactive Tour lets you try the workflow without choosing a file.

  • System requirements: macOS 12 Monterey or later; Intel or Apple silicon Mac
  • Supported files: .md, .markdown, .mdown, .mmd, .txt, and .text
  • Account required: No
  • Data handling: Local by default; see the Privacy Policy

Quick start

  1. Launch FastMD and choose Start Interactive Tour to try in-place formatted-text editing, table tools, multilingual Listen, and native Mermaid in an unsaved document. You can reopen it later from Help → Open Interactive Tour.
  2. Open an existing Markdown or plain-text file from the welcome window, File → Open, or Finder.
  3. Click a rendered block to edit it in place while the rest of the document remains rendered.
  4. Hover over the right side of the title bar, then click Listen to hear the document from the active block or current reading position. The current rendered block is highlighted as narration advances.
  5. Use View → Source Mode to inspect or edit the complete source.
  6. Select a supported file in Finder and press Space to use the bundled Quick Look preview.

Frequently asked questions

Does the Interactive Tour modify a file?
No. The tour starts as an unsaved, in-memory document. No document file is created or modified until you explicitly choose File → Save.

How does multilingual Listen work?
FastMD reads the rendered document block by block and uses available macOS system voices as supported languages change. The visible title-bar control changes to Stop during playback. The same action is available under View → Listen to Document.

What does Summarize Document require?
The optional reading assistant requires macOS 26 or later, a Mac that supports Apple Intelligence, Apple Intelligence enabled, and an available on-device model. Open a small Markdown document in Preview mode, then choose View → Summarize Document…. Summaries and follow-up questions run on-device; unsupported systems or hardware hide the assistant. Core editing still supports macOS 12 and Intel Macs.

Why does FastMD ask for folder access?
Folder access lets FastMD display relative local images, show Markdown files in the same folder, follow atomic saves made by other editors, and remember access between launches. You can choose Not Now; the open document remains usable, but those folder-dependent features may be limited.

Does FastMD upload my documents?
Not in the background. Documents stay on your Mac unless you explicitly choose Publish Preview…. Before any transfer, FastMD names the operator that will receive the HTML snapshot and referenced local resources, says how long the link lasts, and asks you to accept that operator's terms and continue — separately for each operator. The countdown in the publish sheet chooses the lifetime and remembers it: 1 hour publishes through Cloudflare's documented temporary-preview API (which may fall back to the official Drop page in the visible publish sheet), and 24 hours publishes through here.now's documented anonymous publishing API, with no fallback. The resulting link is temporarily public.

Why does a Markdown feature appear as source text?
FastMD intentionally implements a focused, safe Markdown subset. Unsupported or ambiguous constructs remain editable as source rather than being discarded or rewritten.

How do I report a problem?
Include your macOS version, the smallest Markdown or plain-text example that reproduces the issue, what you expected, and what happened.

Bug reports, feature requests, or privacy questions: oldcai.com@gmail.com

FastMD — 支持

FastMD 是一款原生 macOS 编辑器：Markdown 文档保持排版后的阅读状态，只在原位编辑当前文字块。将指针移到标题栏后显示的 Listen 控件会使用可用的系统语音逐块朗读；内置的交互式导览无需选择文件即可体验完整工作流。

  • 系统要求： macOS 12 Monterey 或更高版本；Intel 或 Apple 芯片 Mac
  • 支持文件： .md、.markdown、.mdown、.mmd、.txt 和 .text
  • 是否需要账户： 不需要
  • 数据处理： 默认仅在本机；详见隐私政策

快速上手

  1. 启动 FastMD，选择 Start Interactive Tour，可在未保存的导览文档中体验格式文字原位编辑、表格工具、多语言朗读和原生 Mermaid。之后可通过 Help → Open Interactive Tour 重新打开。
  2. 从欢迎窗口、File → Open 或访达打开已有的 Markdown 或纯文本文件。
  3. 点击排版后的文字块即可原位编辑，其余文档保持渲染状态。
  4. 将指针移到标题栏右侧，再点击显示的 Listen 控件，从当前编辑文字块或阅读位置开始朗读；朗读推进时会高亮当前文字块。
  5. 通过 View → Source Mode 查看或编辑完整源码。
  6. 在访达中选中支持的文件并按空格键，可使用随附的“快速查看”扩展。

常见问题

交互式导览会修改文件吗？
不会。导览以未保存的内存文档开始。只有你明确选择 File → Save 后才会写入文件。

多语言朗读如何工作？
FastMD 会逐块朗读排版后的文档，并在语言变化时使用 macOS 中可用的相应系统语音。朗读期间，标题栏控件会变成 Stop。也可以通过 View → Listen to Document 启动同一功能。

Summarize Document 需要什么条件？
可选的阅读助手要求 macOS 26 或更高版本、支持 Apple Intelligence 的 Mac、已开启 Apple Intelligence，并且本机模型可用。以预览模式打开一份小型 Markdown 文档，再选择 View → Summarize Document…。摘要及后续问答在设备内运行；不支持的系统或硬件会隐藏入口。核心编辑功能仍支持 macOS 12 与 Intel Mac。

为什么 FastMD 会请求文件夹访问权限？
该权限用于显示相对路径本地图片、列出同文件夹 Markdown 文件、跟随其他编辑器的原子保存，并在下次启动时继续访问。你可以选择 Not Now；当前文档仍可使用，但依赖文件夹的功能可能受限。

FastMD 会上传文档吗？
不会在后台上传。除非你主动选择 Publish Preview…，文档始终留在 Mac 上。传输前，FastMD 会点名接收 HTML 快照和引用本地资源的运营方、说明链接时长，并要求你接受该运营方的条款后继续——每个运营方分别询问一次。发布面板上的倒计时用来选择时长并会被记住：1 小时走 Cloudflare 已公开的临时预览 API（必要时在可见发布面板中打开 Drop 官方页面兜底），24 小时走 here.now 已公开的匿名发布 API，没有兜底。生成的链接会暂时公开。

为什么部分 Markdown 功能显示为源码？
FastMD 有意实现了聚焦且安全的 Markdown 子集。不支持或有歧义的结构会保留为可编辑源码，而不会被丢弃或重写。

如何反馈问题？
请附上 macOS 版本、可复现问题的最小 Markdown 或纯文本示例、预期结果和实际结果。
